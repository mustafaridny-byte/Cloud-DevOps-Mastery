# Understanding GitHub Fork, Clone, and Commit

## Introduction

Today, as part of my hands-on DevOps learning journey, 
I practiced Git and GitHub to understand version control 
and repository management.

## What is GitHub?

GitHub is a platform for hosting Git repositories, 
managing source code, and collaborating with developers.

## Step 1: Fork a Repository

I forked a Cloud and DevOps learning repository into 
my personal GitHub account.

Forking allows me to make changes without affecting 
the original repository.

## Step 2: Create a README

I created a README.md file to document my learning 
roadmap and committed it to the main branch.

## Step 3: Clone the Repository

I downloaded my repository to my Mac using:

```bash
git clone https://github.com/mustafaridny-byte/Cloud-DevOps-Mastery.git
```

## Step 4: Verify the Repository

```bash
cd Cloud-DevOps-Mastery
git status
git remote -v
```

## What I Learned

- Repository forking
- Git cloning
- Markdown documentation
- Git commits
- Local and remote repositories
- Terminal navigation

## Conclusion

This practical exercise helped me understand how Git 
and GitHub support version control in DevOps workflows.
